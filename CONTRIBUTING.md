# Contributing

This is a sequential AI relay on one shared game. The engine, first playable scope, and full wave order are not finalized.

1. Agree on the next wave's goal before substantial implementation.
2. Start from the previous reviewed checkpoint on a separate branch.
3. Open a pull request explaining the changes, AI setup used, and testing performed. State clearly if it has not been tested.
4. Include comparable before/after evidence and handoff notes for the next wave.
5. Have the change reviewed before merging. Preserve the working baseline and do not overwrite another contributor's work.

Only contribute original work you have the right to share under the MIT License. Document the source and license of any permitted third-party dependency or asset separately; do not assume the repository license covers it.

Never commit secrets, private notes, proprietary game source, extracted game assets, or assets without redistribution rights. Keep paid tools and model API usage within the project's explicitly approved budget.
