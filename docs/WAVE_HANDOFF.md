## Final wave only — Opus 5.5

Replace the next-goal section with a release report: final checkpoint, run instructions, delivered features, tests, comparison footage, known issues, asset redistribution status, and remaining decisions. Do not create a sixth wave or treat the report as automatic release/deployment approval.
