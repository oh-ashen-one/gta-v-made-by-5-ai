## Concrete entry and API

`res://src/world/geography/source_world.tscn` instantiates `source_world.gd`. `auto_boot=true` starts an asynchronous one-time `boot()`. A caller can set `auto_boot=false`, explicit dataset directories, and `build_mbs` before adding it, then await `boot()`. Missing/changed artifacts, an unsuccessful native commit or unsafe actor arrival fail loading rather than creating substitute ground.

Public services are returned by `services()` and the `source_consumers_ready` signal: the shared frame, context, runtime, domain, roads, city provider/installer, terrain installer, production actors and optional MBS site/stack/hotel. Existing main, mission, traffic and save modules were not modified by this child. No fake WorldBuilder is inserted to satisfy the old HUD type.

`source_world_ready` emits its bounded receipt only after scene/native insertion, runtime region registration and all three actual actor bindings. `canonical_actor_position()` subtracts/adds through the shared frame. `report()` retains actual source identities, actor arrival source IDs, assembly datum and explicit unfinished migration flags.

Only after separate corrected-road native approval, Root adds `--source-world-test-approved-roads`; the default is fail-closed. This acknowledgement cannot override the known-rejectedR2hash. Its normal initial fixture excludes the separately active MBS assembly; `--source-world-test-with-mbs` enables the actual site/stack/hotel path. ## Native support, residency and water

Every source collider keeps exact logical/fragment/way metadata. Runtime support registry IDs are grouped by tile/type, with original per-body IDs retained in `support_id`. Groups split at4096bodies rather than omitting identities. Their bounded volumes use `dry=false`: they are identity envelopes only. A volume does not create physical support; a current ray contact against the stamped native triangles is required. They are not land masks, dry floors, water columns or source surveys.

Each exterior region references the complete currently loaded static source neighborhood, including adjacent overhangs. The current assembly pins those nine tiles. MBS site/floor/cabin modules retain their separate architectural/transport authorities; Root must reconcile dynamic collision completeness and pin/retirement semantics during the full migration. The entry must not treat a static neighborhood receipt as proof that arbitrary unloaded upper floors exist. Source region Y envelopes do not invent support at their lower bound.

The domain keeps outdoor land/water unknown. Root approved a separate local native vehicle-exit policy: current territory-inside, resident, physically supported, clear capsule and not known submerged. Unknown water stays unknown. Cold-source-save restore retains its stricter checks; it is not made ready by the exit rule. No terrain tile box is declared dry to get out of a vehicle.

Initial actor positions are selected through bounded source-space searches with actual center/corner support rays and native shape clearance. Unsupported coast/water, holes and missing tiles do not become flat arrival land. The car's preferred arrival uses the next original-node position on the pinned primary source graph route; heading uses its following original-node direction. That is arrival placement, not proof that the route is driven or currently legally traversable.
